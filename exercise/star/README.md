# 星空生日祝福页面

这是一个基于原生 HTML、CSS 和 JavaScript 实现的星空生日祝福页面。页面将星空背景、烟花动画、生日日期判断、气球效果、动态文字和音乐播放器组合在同一个交互页面中。

│  └─ js/

## 二、文件功能说明

### `index.html`

主页面结构，负责组织以下内容：

- 全屏烟花 Canvas
- 星空背景容器
- 生日标题和页面主标题
- 农历日期提示与倒计时区域
- 公历日期、农历日期和实时钟表
- “查看七月初八”按钮
- 左下角音乐播放器

页面通过以下两个脚本启动交互功能：

```html
<script src="static/js/fireworks.js"></script>
<script src="static/js/script.js"></script>
```

### `static/css/style.css`

页面主样式文件，负责：

- 星空背景和页面整体布局
- 烟花、日期按钮和播放器的位置
- 生日标题的逐字弹跳动画
- “薯条大王”的逐字波浪摇曳动画
- 特殊日期消息和倒计时样式
- 气球外形、高光和上升动画
- 日期卡片翻页动画
- 播放器、播放列表和播放模式按钮样式
- 移动端响应式布局

### `static/css/fireworks.css`

烟花画布的基础样式文件，确保 HTML 和 Canvas 占满视口并隐藏页面滚动条。具体烟花视觉效果由 `fireworks.js` 完成。

### `static/js/script.js`

页面主逻辑，负责：

- 动态生成大、中、小三种星星
- 星星随机漂移和闪烁
- 显示实时公历时间
- 使用浏览器农历格式化器显示农历日期
- 判断当前日期是否为农历七月初八
- 根据日期切换生日标题、祝福内容和倒计时
- 生成并清理生日气球
- 在生日当天尝试播放生日歌曲
- 管理音乐播放器、歌单、进度条和播放模式

### `static/js/fireworks.js`

烟花动画逻辑，负责：

- 根据设备像素比调整 Canvas 清晰度
- 创建幽灵烟花、闪光烟花和马尾烟花
- 更新粒子位置、重力、寿命、透明度和拖尾
- 随机排列烟花播放顺序
- 点击烟花按钮播放连续烟花
- 每个整点自动触发一组烟花

## 三、核心功能

### 1. 星空背景

页面加载时会动态创建大量星星，并按大、中、小三种尺寸设置不同的闪烁动画。星星还会沿随机轨迹缓慢漂移，形成动态夜空效果。窗口尺寸变化时会重新生成星星，以适配新的视口。

### 2. 动态文字

页面包含两种主要文字动画：

- 顶部生日标题 `🎂 生日快乐 🎂`：每个字符独立上下弹跳并发光，仅在生日状态下显示。
- 页面主标题 `🍟 薯条大王 🍟`：每个字符按照不同延迟上下浮动并轻微旋转，形成连续波浪效果。

### 3. 日期和农历信息

页面中央显示：

- 当前公历年份
- 当前月份和日期
- 实时时间
- 农历年份、生肖、月份和日期

日期发生变化时，月份或日期卡片会播放翻页动画。

### 4. 农历七月初八生日状态

脚本根据年份映射表判断当天是否为农历七月初八：

- 生日当天显示生日标题
- 显示生日祝福文字
- 播放气球上升动画
- 隐藏倒计时
- 尝试自动播放 `birthday.mp3`

非生日当天则显示“今天是”和日期相关提示，并提供查看日期按钮。

### 5. 烟花效果

点击右下角烟花按钮后，会随机播放多组烟花。烟花类型包括：

- 幽灵烟花：速度较慢，逐渐消散
- 闪光烟花：亮度高，闪烁明显
- 马尾烟花：带有明显的长尾轨迹

烟花画布覆盖整个页面，但不会阻挡其他按钮和播放器的操作。

### 6. 音乐播放器

左下角播放器支持：

- 播放和暂停
- 上一首和下一首
- 展开或收起播放列表
- 选择指定歌曲
- 拖动播放进度
- 显示当前播放时间和歌曲总时长
- 单曲循环
- 顺序播放
- 随机播放

音乐文件通过相对路径加载，例如：

```text
music/birthday.mp3
music/music1.mp3
music/music2.mp3
music/music3.mp3
```

浏览器通常会限制页面自动播放音频，因此首次打开页面时可能需要手动点击播放按钮。

## 四、页面布局

桌面端布局如下：

- 中央：星空日历和动态文字内容
- 左下角：音乐播放器
- 右下角：烟花按钮和“查看七月初八”按钮
- 背景层：星星和全屏烟花 Canvas

三个底部控件保持同一水平基线，烟花按钮和日期按钮之间保留固定间距，避免互相遮挡。

移动端会自动缩小播放器和按钮宽度，并调整左右边距，保证页面内容不会溢出屏幕。

## 五、运行方式

这是一个无需构建工具的静态网页项目，可以直接打开：

```text
exercise/star/index.html
```

也可以使用 VS Code 的 Live Server 或其他静态文件服务器运行。建议通过静态服务器打开，以获得更稳定的音频加载和浏览器行为：

```text
http://localhost:端口号/exercise/star/index.html
```

## 六、最终实现效果

打开页面后可以看到一个带有动态星空背景的生日祝福页面：

1. 中央显示实时公历和农历日期。
2. “薯条大王”文字持续进行错落的波浪摇曳动画。
3. 到达农历七月初八时，顶部显示发光的“生日快乐”标题。
4. 生日状态下会出现气球上升效果，并尝试播放生日歌曲。
5. 点击烟花按钮会在全屏范围内播放随机组合的烟花动画。
6. 左下角播放器可以管理多首音乐、切换歌曲和播放模式。
7. 页面在桌面端和移动端都能保持基本布局和操作可用。

## 七、维护提示

- 新增音乐时，需要将文件放入 `music/`，并在 `static/js/script.js` 的 `songs` 数组中添加歌曲标题和文件名。
- 修改生日日期时，需要同步调整 `getLunarJulyEighthDate()` 中的年份映射表。
- 修改播放器或底部按钮位置时，优先检查 `static/css/style.css` 中的固定定位和移动端媒体查询。
- 修改烟花种类时，通常需要同时调整 `static/js/fireworks.js` 中的粒子创建函数、序列函数和渲染逻辑。
