星空粒子动画

流星效果

流星随机划过夜空，留下美丽的光迹。每颗流星都有不同的轨迹和速度，模拟真实的流星雨效果。

核心CSS代码


/* 星星基础样式 */
.star {
    position: absolute;
    background-color: white;
    border-radius: 50%;
}

/* 大星星闪烁动画 */
.star.large {
    width: 4px;
    height: 4px;
    box-shadow: 0 0 10px 2px rgba(255, 255, 255, 0.8);
    animation: twinkle-large 5s infinite alternate;
}

/* 中等星星闪烁动画 */
.star.medium {
    width: 2px;
    height: 2px;
    box-shadow: 0 0 6px 1px rgba(255, 255, 255, 0.6);
    animation: twinkle-medium 4s infinite alternate;
}

/* 小星星闪烁动画 */
.star.small {
    width: 1px;
    height: 1px;
    box-shadow: 0 0 4px 1px rgba(255, 255, 255, 0.4);
    animation: twinkle-small 3s infinite alternate;
}

/* 流星样式 */
.shooting-star {
    position: fixed;
    top: 0;
    width: 150px;
    height: 2px;
    background: linear-gradient(90deg, 
        rgba(255,255,255,0) 0%, 
        rgba(255,255,255,1) 70%, 
        rgba(255,255,255,0) 100%);
    border-radius: 50%;
    z-index: -1;
    opacity: 0;
}

/* 流星轨迹 */
.shooting-star::before {
    content: '';
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    background: linear-gradient(90deg, 
        rgba(173,216,230,0) 0%, 
        rgba(173,216,230,0.8) 50%, 
        rgba(173,216,230,0) 100%);
    filter: blur(5px);
    border-radius: 50%;
}

/* 流星动画 */
@keyframes shooting-star {
    0% {
        opacity: 0;
        transform: translateX(0) translateY(0) rotate(45deg);
    }
    10% {
        opacity: 1;
    }
    90% {
        opacity: 1;
    }
    100% {
        opacity: 0;
        transform: translateX(1000px) translateY(500px) rotate(45deg);
    }
}

/* 星系旋转动画 */
@keyframes rotate-clockwise {
    0% {
        transform: rotate(0deg);
    }
    100% {
        transform: rotate(360deg);
    }
}

@keyframes rotate-counterclockwise {
    0% {
        transform: rotate(0deg);
    }
    100% {
        transform: rotate(-360deg);
    }
}

/* 行星浮动动画 */
@keyframes float-planet-1 {
    0%, 100% {
        transform: translateY(0) translateX(0);
    }
    25% {
        transform: translateY(-30px) translateX(20px);
    }
    50% {
        transform: translateY(0) translateX(40px);
    }
    75% {
        transform: translateY(30px) translateX(20px);
    }
}
